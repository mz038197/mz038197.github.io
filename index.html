關於我About me

擁有 10 年的軟體工程師經驗，從使用 ASP.NET、Vue3 搭配 MS SQL 進行網頁全端開發，到使用 Python 搭配 TensorFlow、Keras 為產線打造第一套深度學習影像辨識系統，以及使用 Java 進行安卓應用程式開發等多種程式語言與大型專案開發。

多年的技術背景讓我對邏輯思維、問題解決能力和團隊協作有深刻理解，這些能力正是學習程式設計的基礎。因為熱愛分享知識，決心投入教育領域，特別專注於啟發孩子的想像力與邏輯思考能力，幫助孩子面對未來的挑戰更有自信。

I spent 10 years as a software engineer: full-stack web development with ASP.NET, Vue3 and MS SQL; building the first deep-learning image recognition system for a production line with Python, TensorFlow and Keras; and Android app development in Java, across many languages and large projects.

That background taught me logical thinking, problem solving and teamwork, which are exactly the foundations of learning to code. Because I love sharing knowledge, I moved into education, with a focus on sparking children's imagination and logical thinking so they can face future challenges with confidence.
